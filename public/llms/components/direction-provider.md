# DirectionProvider (阅读方向提供器)

> 直接透传 Base UI DirectionProvider，为 LTR / RTL 国际化界面提供统一方向上下文。

## Installation (shadcn CLI)

```bash
npx shadcn@latest add @glaze/direction-provider
```

- **Registry JSON**: `/r/direction-provider.json`
- **Import Path**: `@/components/ui/direction-provider`
- **Exports**: `DirectionProvider`
- **Base UI Primitive**: `@base-ui/react/direction-provider` ([Base UI Docs](https://base-ui.com/react/components/direction-provider))
- **NPM Dependencies**: `@base-ui/react`

## API Reference

### DirectionProvider

Inherits standard Base UI / HTML element props.

## Source Code

```tsx
export { DirectionProvider } from '@base-ui/react/direction-provider'
```
