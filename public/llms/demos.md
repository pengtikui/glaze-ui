# Glaze 6 Full-Page Business Demos

Each demo can be viewed standalone at `/view/demos/<slug>` (outside the docs frame) or installed via shadcn CLI.

| # | Title | Standalone Route | Registry CLI | Description |
| --- | --- | --- | --- | --- |
| 01 | 家庭内网总控中心 (`HomelabDemoPage`) | `/view/demos/homelab` | `npx shadcn@latest add @glaze/demo-homelab` | 管理物理主机、群晖 NAS、Docker 容器、应用发射台、硬件温度与家庭网络拓扑的内网总控仪表盘。 |
| 02 | 研发协作工作台 (`WorkspaceDemoPage`) | `/view/demos/workspace` | `npx shadcn@latest add @glaze/demo-workspace` | 覆盖迭代里程碑、CI/CD 部署状态、双列迷你看板、甘特排期、团队贡献榜与代码热力图的研发协作中心。 |
| 03 | 全屋智能家居中控 (`SmartHomeDemoPage`) | `/view/demos/smart-home` | `npx shadcn@latest add @glaze/demo-smart-home` | 面向大屏平板与桌面的智能家居控制中心，集成房间传感器矩阵、空调温控、灯光滑块与全屋场景一键联动。 |
| 04 | SaaS 营收与财务驾驶舱 (`AnalyticsDemoPage`) | `/view/demos/analytics` | `npx shadcn@latest add @glaze/demo-analytics` | 融合 Recharts v3 交互式多视图趋势、全年双轴组合分析、转化漏斗、收入构成与多维指标对比的经营分析大屏。 |
| 05 | 个人效率与数字生活 OS (`PersonalOsDemoPage`) | `/view/demos/personal-os` | `npx shadcn@latest add @glaze/demo-personal-os` | 整合番茄钟、交互待办清单、习惯打卡矩阵、日历议程、心率饮水与灵感速记的个人数字生活仪表盘。 |
| 06 | 云原生运维与可观测性中心 (`CloudOpsDemoPage`) | `/view/demos/cloud-ops` | `npx shadcn@latest add @glaze/demo-cloud-ops` | 展示全站 30 日 SLA 状态、集群资源三环监控、告警事件日志、散点延迟分布与全局命令栏的 SRE 运维中心。 |
